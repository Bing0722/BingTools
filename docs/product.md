# 首版范围与验收

状态：框架规划，尚未实现。版本：0.1。

## 定位

BingTools 暂定位为可扩展的桌面工具工作台。当前目标是建立统一的桌面外壳、开发规则和设计体系，具体工具功能由后续需求确定。

主要使用路径：打开程序 → 从左侧进入页面 → 在右侧完成任务 → 进入设置调整外观 → 重启后恢复偏好。

## 第一版交付范围

| 内容 | 验收条件 |
| --- | --- |
| 工程骨架 | Electron 能在开发环境启动，类型与构建配置可执行 |
| 单窗口外壳 | 左侧导航、右侧标题与正文区域布局稳定 |
| 导航与路由 | 工作台、列表示例、详情示例、设置之间可切换，选中状态正确 |
| 主题 | 支持浅色、深色、跟随系统，重启后保留偏好 |
| 侧栏 | 支持用户折叠，窄窗口临时折叠不覆盖用户偏好 |
| 设置持久化 | 设置读写贯通三个进程层次，错误有反馈，损坏文件可恢复 |
| 基础组件 | 按钮、菜单、提示、弹窗和表单具有一致风格与键盘行为 |
| 状态示例 | 可以检查加载、空白、失败和正常页面状态 |
| 桌面行为 | 窗口拖动、缩放、关闭及位置恢复在目标平台验证 |
| 打包 | 在已确定的目标平台生成并启动安装后的应用 |

导航中的示例页面用于验证框架，不算业务功能。禁止使用看似可用但没有行为的按钮掩盖未完成内容。

## 实施顺序

1. 初始化项目与检查脚本，打通最小窗口和页面加载。
2. 建立语义样式变量、基础组件、AppShell 与路由。
3. 实现设置契约、校验、持久化与主题恢复。
4. 加入示例列表和详情页，完善键盘、焦点、滚动及错误状态。
5. 完成关键逻辑测试、实际桌面检查与目标平台打包。

侧栏拖拽调宽、全局命令面板和辅助预览面板作为后续增强，不阻塞最小框架完成。

## 暂不包含

账号登录、云同步、AI 对话、模型管理、终端、代码编辑器、插件市场、远程更新服务和多窗口工作区均不属于当前范围。引入这些功能前补充业务目标、数据模型和权限边界。
