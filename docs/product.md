# 仿真范围与验收

包含 HTTP 与运控串口仿真。实现状态以代码与 [验证记录](verification.md) 为准。

## 产品定位

BingTools 是本地 HTTP Mock 桌面工具。程序作为服务器启动监听，由外部客户端访问；不是向远程服务器发送请求的调试器。TCP 也作为服务端，由客户端接入。

主要路径：新增客户 → 新增接口、填写响应并启用 → 手动启动 → 客户端请求 → 查看日志 → 停止服务。

## 已实现范围

- 导航包含服务器仿真、运控仿真和设置；首页与旧演示路径重定向到 `/simulator`。
- 客户新增、复制、改名、删除；每个客户拥有独立 IP、端口和接口配置。新增可从已有客户复制，保留接口启用状态但不启动服务；名称去首尾空格、忽略大小写判重。改名保留接口。
- 连接方式支持 WebAPI（HTTP）与 TCP，默认 `127.0.0.1:8080`。支持合法 IPv4/IPv6 和 `0.0.0.0`，端口 1–65535；是否可绑定由操作系统判断。
- HTTP／TCP 合计一次仅运行一个客户；运行时锁定客户与监听地址，接口保存和开关立即影响后续请求。
- 接口名称、URL 路径、方法、响应格式、状态码、响应内容和独立启用开关。新增接口默认关闭。
- 方法支持 GET、POST、PUT、PATCH、DELETE、HEAD、OPTIONS；按方法与路径精确匹配，不匹配查询参数。相同客户下重复方法＋路径不可保存。
- 固定 JSON 或纯文本响应，JSON 保存前校验，自动设置 Content-Type；默认 200，允许最终响应状态 200–599；HEAD、204、304 没有正文。
- 顶部监听地址与端口在失焦或 Enter 后自动保存，启动与切换前等待保存完成；客户编辑弹窗与接口内容仍显式保存。无效或保存失败的草稿保留，离开页面时仍可保存／放弃／取消。
- 请求和响应各限制 1 MiB。每客户最多 500 个接口、最多 100 个客户。
- 关闭窗口停止服务，最多等待 3 秒再断开残余连接；重新打开、重启后始终停止。启用偏好保留。

## 日志与通知

日志位于页面下方，独立滚动和收起；记录客户、时间、级别、方法、路径、状态码和耗时，以及服务生命周期事件。只保留当前应用会话最近 1000 条，不写磁盘；客户切换时筛选对应日志。支持级别筛选、搜索、暂停滚动和清空；暂停滚动不影响接收。

详情以文本展示请求头及正文预览。Authorization、Cookie、token、API key 等头部脱敏，请求／响应预览分别最多 8 KiB，不截断 UTF-8 字符。用户填写的响应和原始请求正文不会被翻译。

普通保存、删除、主题、语言及侧栏操作不弹成功提示；重要服务启停和可用更新提供提示；启动失败、保存失败、服务异常通过轻提示反馈并保留在通知中心，客户区域不再展示错误横条。标题栏显示未读数，通知中心保留本会话最近 100 条重要事件，可标记已读、清空。5 秒内同代码通知合并。普通请求只记日志，不逐条弹通知。

## 语言和外观

支持简中、英文、跟随系统；中文系统映射简中，其他映射英文。切换即时生效并持久化，覆盖界面、自定义菜单、校验、通知和系统事件；用户客户名、接口名、URL 和正文保持原值。时间采用所选语言格式。

保留浅色／深色／系统主题、侧栏折叠和四档宽度。中间区域为响应式接口卡片网格，窄窗自动减少列数，下方日志仍可见。

## 不包含

脚本执行、条件响应、远程请求调试、HTTPS、自动启动、操作系统通知、账号、云同步、AI 对话、插件市场。尚未接入签名、公证；已接入公开发布流程，Windows 构建通过，交互与安装仍待实机验证，Linux 未验证。

## 验收入口

`pnpm test` 验证服务、配置和边界；`pnpm test:desktop` 在独立临时数据目录驱动真实 Electron 窗口并发送真实 HTTP 请求。先运行 `pnpm build`。完整执行记录、产物位置及限制见 [验证记录](verification.md)。

## 应用更新与版本发布

更新源为公开 GitHub 仓库 Bing0722/BingTools；设置显示当前版本、新版本及文本更新说明，版本由 package.json 统一管理。Windows x64 和 macOS ARM64 在 GitHub Actions 原生打包，版本标签触发发布。Windows 使用 NSIS 更新；未签名 macOS 提供 GitHub 手动下载入口。实际验收范围见验证记录。

JSON 响应可一键美化并即时判断格式，格式错误禁用美化且保存失败；文本模式允许任意文本。美化不会自动保存或改变正在运行的响应。

接口通过卡片查看和独立开关，通过弹窗新增/编辑/删除。拖动手柄或方向键排序并自动保存；失败恢复原顺序。关闭编辑弹窗提供保存／放弃／取消，不因排序丢失配置。排序不改变 HTTP 匹配规则。

设置可选择通知轻提示的左上、右上、左下、右下位置，默认右下角，立即生效并持久化；标题栏通知中心入口保持固定。

## 运控仿真

与 HTTP 客户配置隔离，支持客户复制和改名、串口参数、规则卡片排序及弹窗编辑。自动匹配完整接收帧并回复固定文本/HEX，手动发送配置的回复，与自动应答开关独立。一次打开一个已存在的系统串口，不安装驱动或创建虚拟 COM 对。不执行运动控制算法、脚本、协议 CRC 或自动重连。

默认 UTF-8 规则和 LF 结束符分包，支持 HEX、任意 1–16 字节结束符、1–65536 字节定长、10–5000ms 空闲分包。分包规则属于客户，接口接收字节必须唯一；运行中只能修改规则，客户和串口参数停止后修改。单条内容 64 KiB，队列上限 100 条，发送超时 3 秒。普通接收与发送只记日志。

日志保留最近 2000 条，单条预览 2 KiB，100ms 批量 IPC，固定行高虚拟列表；暂停只暂停跟随滚动。每 200ms 一条的 Mock 测试覆盖连续应答，未声称完成长时间硬件压力测试。真实硬件与虚拟端口对的系统创建不在本轮验收范围。

运控接口支持分包后的可选尾部预处理：先移除存在的指定 HEX 尾符，再忽略固定尾部字节（0–256）。不验证校验和；过度截断不匹配，歧义不回复。旧规则默认不处理，日志仍保留预处理前的帧。


## TCP 服务器仿真（0.5.0）

支持客户选择 TCP，配置 HEX 结束符与 JSON 点分字段路径或文本分隔符／零起始序号。提取值作为接口名称精确匹配（区分大小写），返回固定 UTF-8 JSON／文本；未匹配、关闭或无效消息只记日志。默认换行分帧、回复追加结束符，支持拆包和粘包。原有客户、卡片排序、热更新、日志、通知和语言继续复用。监听与规则设置停止后修改，不执行脚本、不提供 TLS、TCP 客户端或任意二进制协议解析。

### TCP 特殊协议扩展（0.6.0）

可选固定宽度 ASCII 十进制／十六进制长度头 + UTF-8 正文 + HEX 尾标。长度按字节或 Unicode 码点计算，可表示正文或整包。按长度剥离包装后继续解析 JSON 或文本，并提取字段匹配接口名称。可自动包装回复；头宽度不足不发送，接收非法头或错误尾标断开连接。不是二进制整数头，不计算校验和，不自动探测协议。

0.6.1 支持 `<HH00000>正文<TT>` 预设及自定义长度数字前后固定文本；仍使用显式长度范围，不自动猜测 `00000` 的含义。整包长度包括固定标志，解析后仍按 JSON／文本字段匹配接口。

WebAPI 接口支持独立延时响应开关和 0–60000 毫秒整数，默认关闭。完整请求接收后等待，运行中保存只影响后续请求，日志耗时包含延时。TCP 不使用此设置。

## 配置导入导出（0.7.0）

服务器与运控分别支持当前模块全部客户、当前客户（含所有接口）、当前客户全部／单个接口导出；只包含正式配置。BingTools-transfer v1 JSON 上限 32 MiB，不接受任意 JSON、直接的旧持久化文件或跨模块／跨协议接口。导入预览给出客户／接口数量及前十项名称，明确确认后执行。

导入要求对应模块停止。客户创建为独立副本，重生成客户及接口 ID，同名自动追加编号；保留连接参数和开关但不自动启动。接口追加到当前客户，重复 HTTP 方法路径、TCP 名称或串口接收字节整批拒绝。遵守每模块 100 客户、每客户 500 接口限制；全部校验及保存成功后发布快照，失败保持原配置。跨机器迁移后需核对监听地址与本机串口。

0.7.1 统一所有页面的输入、下拉、数字步进、复选框与开关。下拉菜单使用应用主题中性色与勾选，支持原生键盘选择和字符搜索；数字框提供内嵌箭头，保留直接输入与方向键。业务规则与保存方式不变，真实 Windows 显示验收仍需目标平台验证。

0.8.0 新增内嵌／系统／本机字体与中英文预览、侧栏主题快捷切换和六套主题色。内嵌 Noto Sans SC 离线使用，本机字体支持检测常用候选及准确名称输入，不提供字体文件安装或远程下载。浅深模式和主题色独立选择，重启保留；旧设置保持原有外观，重置外观恢复新增字段且不影响业务配置。

0.8.2 外观新增可选液态玻璃质感，默认关闭。支持强度预览与应用、关闭保留强度、重启保存及重置恢复；适配浅深色和主题色，仅在应用内部呈现透光、高光与模糊。

0.8.4 正式安装版每次启动后台检查更新一次，发现新版右上角显示红点；下载和安装仍由用户触发。统一更新面板展示版本、下载阶段、进度与错误重试，下载可以在关闭面板后继续，安装前确认并停服保存。导航选中背景渐进移动，页面保持不透明，支持减少动态效果。
