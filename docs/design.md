# 视觉与交互规范

状态：用于 HTTP Mock 与运控串口仿真工作台。

## 1. 风格定位

采用安静、清晰、紧凑的桌面工作台风格，参考左侧导航与右侧工作区的组织方式。使用自己的名称、图标组合与视觉细节，不复制参考产品的品牌标识。

界面应让内容成为视觉中心：中性灰为主体，浅色差区分区域，细边框表达结构，强调色仅用于主要操作、焦点和必要状态。首页以实际工作入口或空状态为主。

## 2. 基础布局

```text
┌──────────────┬────────────────────────────────────────┐
│ 系统窗口留白 │ 标题栏                         通知入口 │
│              ├────────────────────────────────────────┤
│ 服务器仿真   │ 客户 / WebAPI / IP / 端口 / 状态 / 启停 │
│              ├────────────────────────────────────────┤
│              │ 接口卡片网格：拖动排序、独立开关       │
│              │ 点击卡片打开编辑弹窗                   │
│              ├────────────────────────────────────────┤
│ 设置         │ 日志工具栏 + 独立滚动的实时日志         │
└──────────────┴────────────────────────────────────────┘
```

顶部使用贯穿窗口的 56px 自定义标题栏，侧栏与内容位于其下方。macOS 保留原生三色按钮，位置为 (16, 21)，工具栏左侧预留 96px，折叠侧栏不改变按钮位置。Windows 使用原生窗口控制覆盖层，右侧预留至少 160px，按钮颜色随主题同步；菜单栏默认隐藏，Alt 可临时访问原生菜单和快捷键。Linux 保留系统窗口装饰。

| 参数 | 起始值 |
| --- | --- |
| 初始窗口内容尺寸 | 1200 × 800 CSS px，受可用屏幕范围约束 |
| 目标最小内容尺寸 | 800 × 560 CSS px |
| 展开侧栏 | 默认 240px，允许调宽时限制在 200–320px |
| 折叠侧栏 | 56px，仅显示主要导航图标 |
| 页面标题栏 | 56px，与桌面窗口控制留白协调 |
| 导航行高 | 34px |
| 页面外边距 | 正常 24px，窄窗口 16px |
| 侧栏内边距 | 8px |
| 分组间距 | 20px |
| 阅读型页面容器最大宽度 | 880px，居中 |

上述窗口尺寸指内容区域；Electron 的窗口外框与平台装饰需要实际换算。表格、编辑器和预览页可使用全部可用宽度。

窗口内容宽度小于 960px 时默认临时折叠侧栏，保留展开按钮。窄窗口展开导航时使用覆盖面板，避免把主内容压缩到不可用。恢复宽度后还原用户布局偏好。

## 3. 色彩变量

下表为首版建议值，实现时作为统一 CSS 语义变量，再映射给 Tailwind 与 shadcn/ui。页面不得自行硬编码另一套配色。

| 语义变量 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| background | #FFFFFF | #18181B | 主内容背景 |
| sidebar | #F6F6F7 | #141416 | 侧栏背景 |
| surface | #FFFFFF | #202024 | 菜单、弹窗等表面 |
| foreground | #202024 | #F4F4F5 | 主文字 |
| muted-foreground | #62626B | #A1A1AA | 辅助文字 |
| border | #E4E4E7 | #34343A | 装饰性分隔线 |
| control-border | #85858F | #71717A | 需要识别边界的输入控件 |
| hover | #ECECEF | #27272C | 悬停背景 |
| selected | #E4E4E9 | #323238 | 导航选中背景 |
| accent | #2563EB | #60A5FA | 链接、焦点、强调 |
| accent-foreground | #FFFFFF | #111827 | 强调底色上的文字 |
| danger | #B91C1C | #F87171 | 错误、危险操作 |
| success | #15803D | #4ADE80 | 成功状态 |

普通分隔线不承担控件识别功能。对实际使用的文字、按钮、焦点和背景组合进行对比度检查：普通文字目标至少 4.5:1，必要控件边界和焦点指示目标至少 3:1。以上配色仍需在真实界面中验证，不表示已经完成可访问性审计。

主题支持 system、light、dark；system 模式响应系统主题变化。成功或错误同时使用文字、图标说明，不只依赖颜色。

## 4. 字体、间距与形状

- 默认使用系统字体栈：system-ui、-apple-system、BlinkMacSystemFont、Segoe UI、PingFang SC、Microsoft YaHei、sans-serif。
- 代码区域使用系统等宽字体栈；正文保持适合中文的行高。
- 导航 13px / 20px，普通正文 14px / 22px，阅读正文可用 16px / 26px。
- 页面标题 18px / 26px，字重 600；分组说明 12px / 18px。
- 间距限定在 4、8、12、16、20、24、32px 等统一级别。
- 小按钮与导航项圆角 6px，输入框与普通容器 8px，弹窗 12px。
- 图标使用 Lucide，导航图标 16px，工具栏图标 18px，主要空状态图标 32px。
- 图标按钮点击区域至少 32 × 32px；普通按钮高度 32px，主要操作可用 36px。
- 阴影主要用于浮层，普通内容通过空间与分隔线组织。

## 5. 导航交互

侧栏保留服务器仿真、运控仿真和底部设置；移除 HTTP MOCK 与本地工作空间装饰说明。客户及接口卡片放在业务工作区。首版没有用户体系，因此不展示虚假的头像、登录状态或账号菜单。

活动项由路由决定，使用选中背景和较高文字权重。hover、active、focus-visible 为不同状态。长标题单行省略，悬停或聚焦时可显示完整内容。

折叠后导航保留图标与 Tooltip，窄窗口通过覆盖面板访问完整导航。

更多操作可在 hover 和 focus-within 时出现；键盘用户必须能够发现并访问。右键菜单只能作为快捷入口，必要操作仍提供可见按钮或菜单入口。

删除欢迎页、示例列表和详情，不展示未实现的协议或无反馈占位控件。

## 6. 内容区和滚动

AppShell 填满窗口，外层不产生页面级滚动条。侧栏中部与主内容分别控制滚动。标题栏和侧栏底部保持可见。

为布局子项设置合适的 min-width: 0、min-height: 0，避免长文本或内容挤破布局。只在必要容器启用 overflow，避免层层嵌套滚动。

普通页面采用统一 PageHeader：左侧标题与可选说明，右侧放最相关的操作。详情页可以增加返回入口。设置页按外观、布局、应用信息分组。

切换不同页面时默认从页面顶部开始；列表进入详情再返回时，应恢复已有筛选及滚动位置。框架侧栏的滚动不随页面切换重置。

## 7. 页面与组件状态

| 状态 | 表现与行为 |
| --- | --- |
| 加载 | 维持布局，使用局部 Skeleton 或进度反馈，避免整页闪白 |
| 空白 | 简短说明当前没有内容，提供一个明确且可用的下一步 |
| 失败 | 在失败区域说明问题；可重试时提供重试，保留用户输入 |
| 正常 | 展示内容及与当前任务相关的操作 |
| 保存中 | 提供轻量状态反馈，防止同一动作重复提交 |
| 保存失败 | 保留可恢复上下文，提示未保存，允许重试 |
| 禁用 | 表明暂不可用，需要解释时提供辅助文本 |

普通操作成功由界面状态反馈，不弹 Toast；仿真操作错误使用 Toast 并保留在通知中心，避免客户区域插入横条引发布局跳动；JSON 等输入诊断仍在对应字段旁。危险操作使用明确的动作名称，并根据后果提供撤销或确认。

Dialog 打开后焦点进入弹窗，关闭后回到触发按钮。弹窗标题说明任务，底部操作位置保持一致。未保存表单关闭时，根据是否会丢失内容处理确认。

## 8. 键盘、窗口与动效

- Tab / Shift+Tab 遍历交互控件，Enter / Space 按控件语义触发操作。
- Esc 优先关闭最上层可关闭浮层；未保存内容按表单规则处理。
- Cmd/Ctrl+B 切换侧栏，Cmd/Ctrl+, 打开设置；快捷键集中注册并清理，避免重复触发与输入法冲突。
- Cmd/Ctrl+K 仅在命令面板实际实现后注册并展示提示。
- 为主内容提供可访问名称和跳转入口；图标按钮具备 aria-label，工具提示不能代替可访问名称。
- 标题栏空白区域可以拖动窗口，按钮、输入框和菜单触发区域设置为不可拖动。
- macOS 为原生窗口按钮留出空间；Windows 优先保留正确的系统控制、缩放和最大化行为。
- 简单颜色过渡约 120ms；侧栏宽度采用 240ms 缓出动画，文字 160ms 淡入淡出。文字保持挂载、图标不缩小或突然居中；遵守 prefers-reduced-motion，减少动态效果时关闭过渡。

## 9. 风格验收

- 浅色、深色和系统主题下文字、选中、悬停及焦点都可辨识。
- 长中文标题、空列表、错误提示与较大字号不会破坏布局。
- 800 × 560、1200 × 800 及更宽窗口下内容可用，窄窗口导航不会永久覆盖内容。
- 侧栏、标题栏、菜单、弹窗的间距与圆角使用同一套变量。
- 鼠标和键盘均可完成导航、修改设置与关闭弹窗。
- 平台窗口按钮、拖拽区域和应用控件互不干扰。
- 所有截图或演示明确区分样例内容与真实功能。

## 10. 服务器仿真工作区

顶部显示标题、运行状态、客户选择与管理、唯一连接方式 WebAPI（HTTP）、监听 IP、端口和启停按钮。运行时禁止修改监听与客户，显示停止后可编辑的说明。操作错误通过 Toast 和通知中心呈现，不在顶部插入错误横条。

中部仅为接口卡片网格，卡片展示名称、方法、路径、格式、状态码与独立开关。每卡约 250px 起，随窗口自动调整列数；网格独立滚动。点击卡片或编辑按钮打开编辑弹窗，表单独立滚动，保存、关闭、删除固定在底部。方法沿用语义色，空客户和空接口提供新增入口。

日志默认约 240px，较矮窗口压缩至约 140px，独立滚动且可收起；筛选、搜索、暂停滚动和清空固定在工具栏。详情弹窗使用等宽字体展示脱敏头部及正文预览。

窄窗口自动减少卡片列数，编辑弹窗宽度随窗口收缩、最高占 90vh，下方日志独立开合。连接方式仍可见。

通知入口位于标题栏右侧，有未读数；通知中心采用统一 Dialog，提供标记已读和清空。本会话最多 100 条重要事件；最多三个轻提示约五秒后关闭。短时间同代码异常合并计数。事件以代码保留，切换语言后已有文案即时翻译。

未保存切换弹窗统一提供取消、放弃修改、保存；验证失败时保留弹窗与输入。客户和接口删除另有明确确认。简中／英文共享布局，用户业务内容不翻译，时间采用所选语言、24 小时格式，避免日志列换行。

应用图标仍为 Electron 默认图标。主题缩略图使用固定浅深样本；系统主题、多显示器和完整无障碍审计的实际覆盖见验证记录。

## 11. 更新入口

设置页的「应用更新」沿用 settings-section、Button、Dialog 和语义色，显示当前版本、来源／演示标签、状态与进度。真实更新源显示 GitHub 仓库，当前与远端版本使用同一展示格式；更新说明以可滚动纯文本展示。未签名 macOS 展示手动下载原因与 GitHub 下载页。真实源启用后采用检查、下载、重启安装三步，重启前弹窗说明停服和保存。失败持续留在本区域并通知，重启安装不自动触发。

## JSON 响应编辑

响应内容右上方在 JSON 模式提供“美化 JSON”，两空格缩进。输入下方持续显示格式状态，错误时边框和文字使用 danger，并设置 aria-invalid / aria-describedby；解析器提供位置时显示行列，不猜测位置。文本模式不显示 JSON 工具和校验。美化只修改草稿，仍需明确保存，沿用未保存提示。


## 统一动效约定

后续新增交互默认沿用 --motion-fast（140ms）、--motion-panel（240ms）、--motion-ease。页面切换轻微上移淡入；弹窗与遮罩支持打开/关闭；通知轻量入场；按钮、导航、主题卡片和接口选中状态平滑变色。日志面板保持内容挂载，平滑改变高度，收起后隐藏区域 inert，不可通过 Tab 进入；旋转箭头反馈开合。暂停自动滚动时，开合不重置滚动位置。高频 HTTP 日志不做逐条入场动画。

接口开关等待保存时仅标记开关忙碌，保持编辑字段可用并保留输入；不切换整个页面的灰态或“保存中”文案，不额外弹出成功通知。失败使用现有通知中心，保持原有启用状态。减少动态效果偏好关闭上述动效。


## 客户选择、复制与改名

客户下拉框仅在列表为空时显示禁用的“—”；存在客户时只列出真实客户。原铅笔入口在宽窗显示“编辑客户”文字，可修改名称、IP 和端口；窄窗保留带可访问名称及悬停说明的图标，避免顶栏换行挤压编辑区。

新增弹窗在已有客户时显示“复制已有客户”下拉框，默认创建空白客户。选择来源后填入其 IP 和端口，并说明会复制全部接口及启用状态；客户名称由用户另行输入，IP/端口仍可调整。回到空白客户恢复默认监听值。编辑已有客户不显示复制选项。重复名称用通知提示，弹窗及输入保留。沿用统一 Dialog 动效、键盘焦点与窄窗布局。


## 接口卡片和编辑弹窗

卡片右上角提供拖动手柄，避免编辑、选择文字和切换开关时误拖。拖动时来源变淡、目标描边，放下后通过 240ms FLIP 位移平滑排列；排序失败动画回到持久化顺序。键盘聚焦手柄后，上/左移至前一位置，下/右移至后一位置，并播报保存结果。Esc 或拖到网格外取消，不写入配置。减少动态效果时禁用位移动画。

编辑弹窗最大宽 820px，顶部标题和说明、底部操作固定，中间表单滚动。JSON 美化和即时诊断保留；保存成功关闭，失败保留原稿并通知。Esc、关闭按钮、遮罩关闭均检查未保存内容，可保存／放弃／取消，返回卡片后恢复焦点。新建接口默认关闭。

## 通知打扰与位置

仅重要事件及错误显示轻提示；设置和普通保存成功不打扰。设置页提供四角位置选择，默认右下角。左右边距与底部边距 20px，顶部 72px 避开标题栏与窗口按钮；上方从上向下堆叠，下方从下向上堆叠，最多三条，沿用入场动效和减少动态效果。位置设置不改变标题栏通知入口。

## 运控仿真页面

复用服务器仿真的顶部配置、卡片区域与底部日志。客户编辑弹窗集中配置串口与分包参数；页面只显示串口摘要和连接按钮。卡片展示格式、接收/回复预览、自动应答开关与发送按钮；未连接时发送禁用，自动应答关闭不影响手动发送。沿用卡片拖放 FLIP、弹窗与日志开合动效、方向键排序和减少动态效果。

串口日志使用虚拟列表，无逐条入场动画；每行保持 32px，详情显示文本和 HEX。仅显示可见行加缓冲，不让持续串口数据增加 DOM 数量。顶部保持连接状态，所有设备错误通过重要通知反馈。

运控接口区使用 flex:1 填满剩余空间，日志收起至 43px 并保持贴底，展开后按暂停状态恢复跟随。接口编辑提供 HEX 尾符和忽略尾部字节数，说明处理顺序、默认不处理和不验证 CRC。

顶部不显示“本地工作空间”，通知入口保持右对齐。侧栏设置下方不再重复显示品牌和版本；版本仍可在侧栏顶部及设置页查看。

通知入口旁新增“检查更新”按钮；发现新版本以语义 danger 色小红点提示，同时提供可访问文字。检查时图标旋转，遵守减少动态效果；弹窗复用更新区，关闭后不取消主进程检查或下载，不清除红点。

HTTP 与运控日志面板切换页面后保持各自的收起／展开、关键词、筛选及暂停状态；暂停时恢复浏览位置，自动跟随时滚至最新。会话状态不落盘，重启后回到默认；保留路由入场与日志开合动画。


## TCP 配置与接口

服务器页顶部显示当前协议；客户编辑选择 HTTP／TCP，TCP 时展开结束符、提取格式与字段规则，沿用统一入场动画与 reduced-motion。客户弹窗可独立滚动。TCP 接口卡片显示 TCP 和名称；编辑只显示名称匹配说明及回复内容，隐藏 HTTP 方法、路径、状态码，保留显式保存与未保存保护。日志复用现有收起状态、筛选及详情。
