# BingTools 0.6.0

TCP 新增可选「长度头 + 正文 + 结尾标志」特殊协议。支持 1–10 位固定宽度 ASCII 十进制／十六进制长度头；按 UTF-8 字节或 Unicode 码点计数，长度可表示正文或整包。

按长度提取中间正文并校验 HEX 尾标，再使用 JSON／文本字段匹配接口。支持头、正文、UTF-8 字符与尾标拆包和多包粘连；可自动生成同规则回复，头宽度不足不发送。非法头、超限声明或错误尾标断开对应连接，不猜测边界。

旧 HTTP、结束符 TCP 客户迁移至 schema v3，默认行为不变。示例：0016{"action":"get"}#，提取 action 对应接口 get。

Adds configurable text length headers, payload extraction and framed TCP replies.

本轮未发布安装包；Windows 实机及用户真实设备协议未验证。不支持二进制整数长度头、校验和或自动识别协议。
