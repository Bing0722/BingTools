# BingTools 0.4.2

- 修复运控日志收起后不贴底的问题，接口区域自动扩展。
- 接口支持匹配前去除指定 HEX 尾符、随后忽略固定数量的尾部校验字节；默认关闭，旧配置保持原行为。仅忽略字节，不计算或验证 CRC。
- 接收日志保留分包后、预处理前的原始帧；多规则同时匹配时不自动回复。

Fixes motion log collapse and adds configurable receive-tail preprocessing. Legacy rules retain exact matching. Real serial hardware and Windows desktop behavior remain unverified.
