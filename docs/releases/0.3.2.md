# BingTools 0.3.2

## 改进 / Improvements

- 收起侧栏、切换主题和语言、普通保存不再弹通知；错误、服务启停和可用更新等重要事件仍会提示。
- 设置中的通知位置支持左上、右上、左下、右下，默认右下角，立即生效并自动保存；顶部通知避开窗口标题栏。
- v1/v2 设置自动迁移，保留原有语言、主题、侧栏及窗口位置。

Routine actions no longer show notifications. Important events and errors remain visible. Choose any of the four notification corners in Settings; the preference persists across restarts.

## 验证与安装 / Validation and installation

通知改动已通过 38 项测试、生产构建及 macOS 桌面流程。Windows 实机安装与升级尚未验证。本版本尚未打包或发布；升级版本号不会自动发布安装包。

Windows 安装包仍未签名；macOS 仍需从 GitHub 手动下载安装，未签名、未公证。本机客户与设置保存在用户数据目录，HTTP 服务需手动启动。
