# BingTools 0.5.0

服务器仿真新增 TCP 服务端。客户可配置监听地址、HEX 消息结束符和提取规则；支持 JSON 点分字段路径（如 data.action），或按分隔符和序号提取 UTF-8 文本字段，空分隔符表示整帧。

提取值与接口名称精确匹配，返回固定 JSON 或文本，支持独立开关和运行中保存。JSON 回复自动去除字符串外空白，可追加消息结束符。未匹配或格式错误只记录日志，不回复；TCP 不使用 HTTP 方法、路径和状态码。

每连接独立处理拆包／粘包，单帧和响应上限 1 MiB；最多 64 连接，空闲 60 秒关闭，发送缓冲有界。停止或关闭窗口释放服务，重启不自动监听。旧 HTTP 配置迁移到 schema v2，内容保持。

Adds TCP server simulation with JSON/text field routing and bounded delimiter framing.

不包含 TLS、二进制协议解析、脚本或 TCP 客户端模式。本轮未发布安装包；Windows 实机未验证。
