# BingTools 0.3.0

首个 GitHub Releases 版本 / First GitHub release.

## 新增 / Added

- 客户独立配置、HTTP Mock 接口编辑、开关和运行中更新。
- 实时日志、请求头脱敏、应用内通知、简体中文和英文界面。
- GitHub Releases 更新检查、下载进度及版本更新说明。
- Windows x64 NSIS 安装包；macOS Apple Silicon DMG / ZIP。
- 推送版本标签后，GitHub Actions 自动测试、构建并发布安装包及更新元数据。

## 安装说明 / Installation

- Windows：下载 `BingTools-0.3.0-win-x64.exe`。当前安装包未签名，系统可能提示未知发布者。
- macOS Apple Silicon：下载 `BingTools-0.3.0-mac-arm64.dmg` 或 ZIP。当前未签名、未公证，应用内提供 GitHub 下载页，暂不支持原位自动安装。
- 本版本是 GitHub 更新通道的基础版本；此前本地演示包需要手动下载安装。
- Windows: use the x64 EXE installer. The installer is currently unsigned.
- macOS: use the Apple Silicon DMG or ZIP. This build is unsigned and not notarized; update manually from GitHub Releases.

## 保留数据 / Data

更新保留本机 `settings.json` 和 `simulator.json`。仿真服务始终手动启动。
Local settings and simulator configurations are preserved; the HTTP service never starts automatically.
