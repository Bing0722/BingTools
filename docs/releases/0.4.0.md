# BingTools 0.4.0

## 新增 / Added

- 运控仿真页：独立客户新增、复制、改名和删除，串口枚举与参数配置。
- 接口卡片支持文本/HEX 收到指定内容后回复指定内容、自动应答开关、手动发送回复内容、拖动和方向键排序、弹窗编辑及未保存保护。
- 支持结束符、定长、空闲间隔分包；默认 9600 / 8N1 和 LF 结束符。超长帧丢弃，发送队列有界且串行。
- 串口日志每 100ms 批量刷新，保留最近 2000 条，单条预览 2 KiB，虚拟列表仅绘制可见行。

Adds a motion simulator with independent customer profiles, serial settings, text/HEX matching, automatic replies and manual response sending. Bounded batched logs and virtual rows support continuous traffic.

## 使用与限制 / Usage and limitations

打开系统已有 COM/串口，不创建虚拟串口对。HTTP 和串口各自独立运行，关闭窗口释放连接，重启不自动连接。无设备时可先编辑规则，连接前需选择实际可用端口。

串口收发通过 Mock 验证，包含每 200ms 一条消息；真实设备与 Windows COM 实机未验证。macOS 未签名、未公证，仍需手动更新；Windows 安装包未签名。本轮仅本地验证，不代表已发布。详细结果见验证记录。
