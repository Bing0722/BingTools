# BingTools 0.3.1

本次更新改进客户和接口编辑、桌面布局及操作反馈。This update improves customer and endpoint editing, desktop layout, and feedback.

## 新增与改进 / Changes

- 统一窗口标题栏，侧栏展开和收起更平滑；页面、弹窗和日志面板增加轻量过渡，并遵守系统减少动态效果设置。
- JSON 响应支持两空格美化和即时格式诊断；无效内容会标记在输入框旁，保存前仍需通过校验。
- 新建客户时可复制已有客户的监听配置和全部接口；支持客户改名，并阻止重复名称。
- 接口改为卡片网格，可拖动或使用方向键排序；新增、编辑和删除在独立弹窗完成，排序会随客户配置保存。
- 接口开关保存时只显示局部忙碌状态；仿真操作错误通过轻提示和通知中心反馈。

## 安装与更新 / Installation and update

- Windows x64：下载 `BingTools-0.3.1-win-x64.exe`；已安装的 0.3.0 可在设置中检查、下载并确认重启安装，但跨版本安装仍待 Windows 实机验收。安装包未签名，系统可能提示未知发布者。
- macOS Apple Silicon：下载 `BingTools-0.3.1-mac-arm64.dmg` 或 ZIP。安装包未签名、未公证，应用内提供 GitHub 下载页，需手动更新。
- 本机客户与设置保存在用户数据目录，升级不会主动删除；HTTP 服务仍需手动启动。

Windows x64 users can check, download, and start installation from Settings or download the unsigned installer; installation from 0.3.0 still needs validation on a Windows desktop. macOS Apple Silicon users must update manually from GitHub because this build is not signed or notarized. Local settings and customer data remain in the user data directory.
