# BingTools 0.8.5

本次发布汇总自 0.8.0 以来的改动。

- 关闭输入框系统拼写检查，优化侧栏收缩按钮与悬浮提示。
- 外观设置新增液态玻璃开关和强度调节，默认关闭；设置可保存、迁移和重置。
- 监听地址和端口在失焦或按 Enter 后自动保存，启动前等待保存完成；保存失败保留草稿。
- 侧栏选中状态、页面与按钮增加轻量动效；正式安装版启动时后台检查一次更新，更新弹窗显示下载进度和失败重试，开发及演示模式不自动请求网络。
- 修复切换服务器仿真与运控仿真时，整个工作区横移引起的视觉抖动。
- 标题、接口区和日志保持固定位置，侧栏选中背景与按钮动效继续保留。

Windows/Linux 实机、真实安装升级及用户设备协议未验证；macOS 安装包未签名、公证，需手动下载安装。
