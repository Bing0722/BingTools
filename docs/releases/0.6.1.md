# BingTools 0.6.1

TCP 分包协议新增 `<HH00000>正文<TT>` 模板，自动填入固定前缀 `<HH`、5 位十进制正文长度、固定后缀 `>` 和尾标 `<TT>`。长度数字前后文本可自行修改，原有字节／字符、正文／整包选项保持可用。

示例：`<HH00016>{"action":"get"}<TT>`，提取 action 匹配 get 接口。回复可自动使用同样包装；整包计数包含所有固定标志。头标志错误断开连接，旧配置迁移后保留原有行为。

Adds configurable fixed text around TCP length digits and an HH/TT preset.

未发布安装包，Windows 实机和真实设备协议未验证。
