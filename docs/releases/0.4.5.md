# BingTools 0.4.5

本次发布汇总自 0.3.1 以来的改动，新增运控串口仿真，并改进通知、更新入口和日志工作区。

## 新增与改进 / Changes

- 新增独立的运控仿真页：管理客户、串口参数和文本／HEX 收发规则；支持结束符、定长、空闲间隔分包，自动应答与手动发送，以及有界批量日志。只打开系统已有串口，不创建虚拟串口对。
- 运控规则可在匹配前移除指定 HEX 尾符，再忽略固定数量的尾部字节；默认关闭，旧规则保持原行为。不计算或验证 CRC，多条规则同时匹配时不自动回复。
- 标题栏新增检查更新入口和可用更新红点，与设置页共享更新状态；不会自动下载或安装。
- 普通保存与设置操作减少通知，重要事件和错误仍会提示；通知可选择四角位置并持久化。
- 精简标题栏和侧栏文字，修复运控日志收起后的布局；HTTP 与运控日志分别记忆本次会话中的收起、搜索、筛选、暂停及滚动位置。

## 安装与限制 / Installation and limitations

- Windows x64 安装包未签名，系统可能提示未知发布者；真实 Windows COM 设备、从旧版本升级安装尚未实机验收。
- macOS Apple Silicon 安装包未签名、未公证，请从本页手动下载安装；应用内不执行原位自动安装。
- 本机设置、HTTP 客户与运控客户保存在用户数据目录。旧设置和运控配置按版本规则迁移；HTTP 服务与串口连接仍需手动启动。
- 串口收发已通过 Mock 与 macOS 打包应用的原生模块加载验证，真实串口硬件收发和长时间压力运行尚未验收。

Since 0.3.1, this release adds serial motion simulation, configurable receive-tail handling, a header update entry, quieter notifications, and persistent in-session log views. Windows and macOS builds are unsigned. macOS updates require a manual download; real serial hardware and Windows upgrade installation remain unverified.
