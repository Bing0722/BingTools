## 测试覆盖

- HTTP：全部七种方法、精确路径、忽略查询、JSON/文本、404、接口开关、热更新、HEAD/204/304 无正文。
- 异常：端口占用、不可绑定 IP、声明长度及 chunked 请求超过 1 MiB、非法路径/JSON/响应大小/IPC 字段。
- 生命周期：停止释放端口；未完成请求最多等待约 3 秒；关闭窗口停止；macOS 激活重开与重启后不自动监听。
- 配置：客户隔离、重启恢复、重复路由拒绝、运行中监听保护、保存失败不改变运行配置、原子替换失败不更新内存、损坏备份、新版本只读。
- 设置：v1 保留主题/布局/窗口坐标迁移到 v2；语言保存恢复；并发写入不丢字段；非法更新后队列继续。
- 日志：1000 条上限、按客户清空、8 KiB UTF-8 安全截断、认证头/Cookie/API key 脱敏、订阅取消。
- 通知：5 秒内合并、100 条上限、已读/清空/关闭；普通反馈不进入中心。
- 语言：中英文资源键一致、系统 locale 映射、即时切换、重启恢复、已有系统日志/通知翻译、自定义菜单切换。

## 桌面流程

`scripts/smoke.mjs` 使用独立临时数据目录和临时本机端口：

1. 新增客户和接口，保存启用，手动启动。
2. 外部 fetch 获取 JSON；查看日志脱敏详情。
3. 关闭接口得到 404，重新打开并保存新响应，后续请求立即获取新内容。
4. 无效 JSON 保留草稿；离开页面的取消和放弃经过路由阻塞器。
5. 切换深色、英文、浅色；通知标记已读和清空；检查菜单与键盘焦点。
6. 缩小窗口，检查上下分栏、日志收起展开、最小窗口布局。
7. 停止后确认端口不可访问；模拟端口占用，确认页面错误与通知中心。
8. 重新启动服务后关闭窗口，确认端口释放；激活重新打开仍停止。
9. 重启应用后恢复客户、接口、语言和主题，仍不自动监听。

截图输出到已忽略的 `test-results/`，测试数据不提交。初次在受限沙箱内运行 HTTP 测试遇到 `listen EPERM`；允许本机监听后测试通过，没有改用虚拟 HTTP 测试规避验证。
